| 情况                              | 规则                    | 例子                                                |
| --------------------------------- | ----------------------- | --------------------------------------------------- |
| 绝大多数名词                      | 直接加 -s               | cat → cats, book → books                            |
| 以 -s, -ss, -sh, -ch, -x, -z 结尾 | 加 -es                  | bus → buses, box → boxes, watch → watches           |
| 以辅音字母 + y 结尾               | 把 y 改成 ies           | baby → babies, city → cities                        |
| 以元音字母 + y 结尾               | 直接加 -s               | boy → boys, key → keys                              |
| 以 -o 结尾                        | 多数加 -es，部分只加 -s | potato → potatoes<br>photo → photos, piano → pianos |
| 不规则变化                        | 完全改变词形            | child → children, mouse → mice, man → men           |
