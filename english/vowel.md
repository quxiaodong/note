| 元音字母 | 常见例子                 |
| -------- | ------------------------ |
| a        | apple, cat, name, make   |
| e        | egg, bed, he, see        |
| i        | ice, big, like, time     |
| o        | orange, hot, go, home    |
| u        | umbrella, cup, use, blue |
| `y`      | my, happy, fly, system   |

> 使用 a 还是 an，只看后面单词的第一个发音，不看字母。第一个音是元音就用 an，是辅音就用 a。
